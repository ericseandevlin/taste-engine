# Roadmap

Drop in a folder of reference images. Get a rule sheet you can edit, and a poster that obeys it. This file says where that goes next.

## Where we are

One path ships: a folder of references in, an editable rule sheet and a checked poster out, from one command. See the README.

## Next

- **A real poster board in the demo.** The bundled demo board is made of website mockups. A small board of poster references is a truer example.
- **Reference images into the image agent.** The agent draws from the rules alone today. Passing two or three references with the prompt is the next quality step to test.
- **A second fixed surface.** Book cover or title card, through the same rule sheet.

## Parked

A curation app, named tunings of one board for different uses, and a model of taste across boards. None of these starts until the poster path makes work worth keeping.

## Lab

Experiments that are not on the main path are listed in [docs/LAB.md](docs/LAB.md).
