# Code of conduct

This is a small project. The rules are short.

## The standard

- Be kind and direct. Disagree with the idea, not the person.
- Assume the other person means well. Ask before you assume.
- Give feedback you would be glad to get: specific, about the work, with a way forward.
- Keep it on topic. Issues and pull requests are for the project.

## Not OK

- Insults, harassment, or personal attacks.
- Sexual language or imagery, and unwelcome attention.
- Posting someone's private information.
- Posting other people's work as your own, or private reference boards that are not yours to share.

## Where it applies

Issues, pull requests, discussions and any other space that belongs to this project.

## Reporting

Do not report it in a public issue. Go to the **Security** tab of this repo, click **Report a vulnerability**, and start the title with "Conduct". That form is private. Only the maintainer reads it.

The maintainer may remove comments or contributions that break this code, and may ban someone from the project for repeated or serious violations.
