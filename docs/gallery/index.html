Taste Engine / demo gallery GitHub

Taste is data.

01 / Input

The board

Eight synthetic homepage mockups, rendered from the HTML in boards/demo/_sources/. No real sites. Each one gets measured locally, then tagged by a vision model from a fixed vocabulary. Tags outside the vocabulary are thrown away.

02 / Extracted

The profile

The records cluster into DNA channels by what they do, not what they show. Each channel is a recipe plus a list of forbidden moves. The forbidden moves are the part a generator can be held to.

03 / Pass or fail

Build, critique, rebuild

04 / Lanes

Same board, two lanes

The board also yielded other directions. One page from the heaviest lane, one from the loudest, each re-measured with the same extractors the references went through and scored against both lanes. Higher means closer. It is a diagnostic for choosing, not a judge.
